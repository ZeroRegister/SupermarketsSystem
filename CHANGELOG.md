# Release history

## 1.1.0 — Inventory warning expansion

- Auditable warning handling: confirmation, severity, assignment, processing, notes, recovery and recurrence links.
- Batch receipts and allocations; FEFO/FIFO dispatch; quarantine; physical and sellable balances.
- Configurable business timezone, near-expiry window and no-sales rules; periodic detection and failure retry status.
- Purchase recommendations, multi-product drafts, approval, partial receipts and remaining-quantity cancellation.
- Reviewed physical counts, adjustments and batch disposal; stale-count checks and request replay protection.
- MySQL V2–V8 migrations preserve existing inventory, movements and prior confirmations.
- Existing thesis artifacts continue to document the earlier release.

Development checkpoints are individual feature commits on `codex/inventory-warning-expansion`; `v1.1.0-warning-center` marks the integrated upgrade. This is a local release checkpoint; it does not imply a remote push or publication.
